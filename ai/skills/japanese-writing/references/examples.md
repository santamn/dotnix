# 対比例

AI 版と人間版の対比。各例にジャンルのタグを付けてある。タグの無いものは全ジャンル共通。

## 空句

**[全ジャンル]** 姿勢の宣言を、中身に置き換える。

| AI 版 | 人間版 |
| --- | --- |
| 本章では、〇〇の理論を正面から扱う | 本章では、〇〇の理論を扱う |
| この前提を、ここで正面から回収する | ここで、この前提を回収する |
| 多角的に分析すると、重要なのは〜である | 評価の核心は、正しさを誰が知っているかにある |
| この問題について深掘りしていく | この問題には三つの原因がある。順に見る |

## 翻訳調と擬人化

**[全ジャンル]** 主体と対象を具体語で言い直せるか試す。

| AI 版 | 人間版 |
| --- | --- |
| ベクトルが選好を運ぶ | 選好がベクトルとして表現される |
| この問いは開かれている | この問いにはまだ答えが出ていない |
| 推敲の軸が露出する | 推敲の軸が線形に取り出せる |
| モデルは文体を知っている | モデルの出力には文体の一貫性がある |
| データが語るのは〜である | データから分かるのは〜である |
| 規範スキルが効く | 規範スキルを与えると生成が選好に近づく |

## 因果の機構

**[技術文書]** 「AだとBになる」だけで終わらせず、なぜそうなるのかを一文で示す。

- AI 版: 手順で分けると変更が全体に波及する
- 人間版: 各工程がデータを受け渡すための表現を共有してしまい、その表現を変えると全体に波及する

## 異なるものの一括り

**[技術文書]** 区別すべき対象をまとめない。

- AI 版: 相互依存する三つの未決事項を「同じ決定を別々に下していた」と書く
- 人間版: 「どれも別々の決定であり、しかも互いに依存している」と腑分けする

## 漠然とした否定

**[技術文書]** 否定する命題そのものを書き出す。

- AI 版: これで何もかもが解決するわけではない
- 人間版: 「明文化されていればすべてを任せられる」ということは意味しない

## 推量の扱い

**[技術文書]** 不確実性を表す述語は、根拠なく弱めているときだけ削る。

- 悪い直し: 「提示し続けているかもしれない」を「提示し続けている」に変える
- 良い直し: 「提示し続けている可能性がある」のように、不確実性を残して文を整える

## 節末の進行予告

**[読み物]** 節間の推進力は、次節の頭に置く反問や違和感で作る。

- AI 版 (前節の末尾): ここまでで課題は見えた。次は解決策を見ていく。
- 人間版 (次節の頭): では、先に設計を固めておけばよかったのだろうか。そうしたかった、とは思う。

## 装置の実況

**[読み物]** 装置は内容で実現し、操作を宣言しない。

- AI 版: 先に答えを半分だけ置く。
- 人間版: (答えの前半を、そのまま内容として書く)

## 駄文と緩みの区別

**[読み物]** 更新するのが「状況」か「文書」かで判定する。

| 駄文 (文書を更新) | 緩み (状況を更新) |
| --- | --- |
| ここまでだと、概念の説明に見えるだろう | この三つの性質は、どれも冒頭の失敗の中にそろっている |
| 要するに、この章の主題は〜である | まあ、今すぐ手を打つほどでもないのだけど、どこかの時点で整理は要るだろう |
| テクニックの列挙はしない | うまくいっているに違いない |
| 次は〜を見る | 最初からわかっていたらそうしていたのに、というのが口惜しい |

## 命題型 H2

**[個人]** 見出しはテーマの名前で立てる。

| AI 版 | 人間版 |
| --- | --- |
| ## 設計は思想の表れである | ## 設計の決め方 |
| ## 小さく作ることがすべてを変える | ## 分割の単位 |

## 二項対比

**[個人]** 「AではなくB」を「B」と直接書く。

| AI 版 | 人間版 |
| --- | --- |
| 単なるツールではなく、思考の拡張である | 考えるときに使っている |
| 速さではなく、確かさが問われる | 確かさが要る |

## false agency

**[個人]** モノに人間の動詞をさせない。

| AI 版 | 人間版 |
| --- | --- |
| データが示している | 集計してみたら〜だった |
| 文化が醸成される | チームの何人かがそう振る舞い始めた |
| 課題が浮き彫りになる | レビューで三人が同じ点を指摘した |
| 思想が結実する | 最後はこう決めた |

## 強度と中間温度

**[個人]** 全部を最上級にしない。

| AI 版 | 人間版 |
| --- | --- |
| この体験は最高に素晴らしかった | 悪くなかった |
| 圧倒的に便利すぎる | 思ったより使える |
| 完全に理解が変わった | 見方が少し変わった気がする |

## 全方位肯定

**[個人]** 判断を引き受ける。

- AI 版: A にもよさがあり、B にもよさがあります。ケースバイケースで選ぶとよいでしょう。
- 人間版: 自分は A を選んだ。B は設定が多すぎて、二週間で戻した。

## 劇的な断片化

**[個人]** 短文の連打で緊張を作らない。

- AI 版: シンプル。それだけ。それが本質。
- 人間版: やることは一つで、設定ファイルを一枚置くだけだった。

## 一般化

**[個人]** 自分の話を「多くの人」に広げない。

- AI 版: 多くのエンジニアが、現代社会において同じ課題を抱えている。
- 人間版: 自分の場合、同じことで三回つまずいた。
